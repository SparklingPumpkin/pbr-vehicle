# PBR 车辆资产转换使用指南

本交付包将标准 3D Gaussian Splatting 车辆 PLY 转换为可编辑的 PBR 车辆资产。正式转换入口为 `pbr-vehicle complete-asset`。

转换会复制输入车辆的可见 Gaussian，并只追加逐点法线 `normal_0..2`。全局材质参数位于配置文件；不生成 proxy 或映射文件。车辆投影不保存为独立 PLY，而是在运行时根据车辆姿态、太阳方向和配置生成地面 mask。

## 1. 安装

先设置交付包和预设资产库的位置。请将两个路径替换为当前机器上的实际位置；下文命令均使用这两个变量，不依赖特定机器目录：

```bash
export PBR_VEHICLE_ROOT=/path/to/pbr-vehicle-convert
export PBR_ASSET_ROOT=/path/to/pbr_assets

cd "$PBR_VEHICLE_ROOT/package"
python -m pip install .
```

仅做资产转换不需要 GPU。若需要使用 SDK 的图像渲染能力，再安装：

```bash
python -m pip install '.[render]'
```

安装完成后可确认命令已注册：

```bash
pbr-vehicle --help
```

## 2. 使用预设 10010 转换一份新资产

预设资产位于 `$PBR_ASSET_ROOT`，其中 `10010` 已是可直接使用的正式单 PLY 资产。下面命令以普通 3DGS 输入 PLY 为输入，生成一个新的、独立的资产目录。将 `inputs/vehicle_3dgs.ply` 替换为待转换车辆的原始 PLY；输出目录必须尚不存在，或为空目录。

```bash
pbr-vehicle complete-asset \
  inputs/vehicle_3dgs.ply \
  "$PBR_ASSET_ROOT/converted_10010_example" \
  --asset-id converted_10010_example \
  --config "$PBR_VEHICLE_ROOT/package/examples/configs/config_default.json"
```

生成后执行以下命令校验资产目录、文件命名与 SHA-256：

```bash
pbr-vehicle inspect-complete \
  "$PBR_ASSET_ROOT/converted_10010_example"
```

成功后，输出目录包含：

```text
converted_10010_example/
  pbr_converted_10010_example.ply
  configs/
    config_converted_10010_example.json
```

## 3. 命令行参数

| 参数 | 含义 | 约束 |
| --- | --- | --- |
| `input_ply` | 输入车辆的标准 3DGS PLY。不能使用已含 `normal_0..2` 的 `pbr_*.ply` 再次转换。 | 必须存在，且包含 `x/y/z`、`f_dc_0..2`、`scale_0..2`、`rot_0..3`、`opacity`。 |
| `output_asset` | 新资产目录。 | 命令不会覆盖非空目录。 |
| `--asset-id` | 资产唯一标识；用于输出文件名与 canonical 配置名。 | 仅允许字母、数字、`_`、`-`，最长 64 字符。 |
| `--config` | JSON 转换配置。 | 必须提供；可复制默认配置后再修改。 |

`complete-asset` 没有 `--overwrite`。如需重新转换，请使用新的输出目录；不要覆盖已有交付资产。

## 4. 配置文件参数

示例配置位于：

```text
$PBR_VEHICLE_ROOT/package/examples/configs/config_default.json
```

建议将其复制到自己的工作目录后再编辑，再通过 `--config` 指向副本。

### `material`：车辆材质默认值

| 字段 | 含义 | 默认值 |
| --- | --- | --- |
| `roughness` | 车漆粗糙度；低值高光更锐利，高值高光更柔和。 | `0.32` |
| `albedo_rgb` | 全车共享的基础反照率 RGB。单 PLY 不存逐点 albedo。 | `[0.82, 0.82, 0.82]` |
| `metallic` | 金属工作流混合比例；普通车漆通常接近 `0`。 | `0.02` |
| `reflectance` | 非金属表面的基础反射率 F0。 | `0.04` |
| `clearcoat` | 透明清漆层强度。 | `0.35` |
| `exposure` | 车辆材质默认曝光倍率。 | `1.0` |
| `relight_strength` | PBR 光照响应相对输入 Gaussian 外观的强度；`0` 保留原始外观，`1` 完整采用重打光响应。 | `1.0` |

### `light`：默认光照

| 字段 | 含义 | 默认值 |
| --- | --- | --- |
| `sun_enabled` | 是否启用太阳直射光。 | `true` |
| `sun_azimuth_degrees` | 太阳水平方位角，单位为度。 | `126.0` |
| `sun_elevation_degrees` | 太阳仰角，单位为度；投影运行时要求在 `1` 到 `89` 之间。 | `45.0` |
| `intensity` | 太阳光强度。 | `1.0` |
| `color_rgb` | 太阳光 RGB 颜色，三个浮点数。 | `[1.0, 0.98, 0.92]` |
| `environment_color_rgb` | 环境补光 RGB 颜色，三个浮点数。 | `[0.55, 0.62, 0.72]` |

输出 PLY 保留输入的所有可见 3DGS 字段，仅增加 `normal_0..2`。法线取每个 Gaussian 最小协方差轴并统一向车辆中心外侧翻转；材质统一从 `material` 读取。

### `projection`：运行时地面投影

投影采用 `receiver_space_mask_v1`，不会生成或依赖 `projection_*.ply`。它由两层连续 mask 构成：车下固定接触层，以及按当前太阳方向生成的车辆外围轮廓层。

#### 公共字段

| 字段 | 含义 |
| --- | --- |
| `enabled` | 是否启用投影。 |
| `dynamic` | 是否允许运行时随太阳与车辆姿态更新。应保持为 `true`。 |
| `runtime` | 固定为 `receiver_space_mask_v1`。 |
| `shape_model` | 固定为 `procedural-mask-contact-silhouette-v4`。 |
| `composition` | 固定为 `receiver_alpha_blend_to_grayscale_v1`，表示以 mask alpha 向灰度目标压暗接收面。 |

#### `projection.contact`：车下圆角矩形接触层

| 字段 | 含义 | 默认值 |
| --- | --- | --- |
| `shape` | 固定为 `rounded_rectangle`。 | `rounded_rectangle` |
| `alignment` | 固定为 `vehicle_local_xy`，即与车辆局部 XY 轴对齐。 | `vehicle_local_xy` |
| `length_scale` | 相对车辆局部长度范围的缩放；小于 `1` 会向内收。 | `0.92` |
| `width_scale` | 相对车辆局部宽度范围的缩放；小于 `1` 会向内收。 | `0.88` |
| `offset_xy_m` | 局部 XY 偏移，单位米，格式 `[前后, 左右]`。 | `[0.0, 0.0]` |
| `corner_radius_m` | 圆角半径，单位米。 | `0.22` |
| `edge_softness_m` | 边缘模糊宽度，单位米。 | `0.08` |
| `opacity` | mask 覆盖强度，范围 `0` 到 `1`。 | `0.11` |
| `brightness` | 覆盖区域目标灰度，范围 `0` 到 `1`；`0` 为黑，`1` 为白且不压暗。 | `0.18` |

#### `projection.extension`：太阳动态外围轮廓层

| 字段 | 含义 | 默认值 |
| --- | --- | --- |
| `shape` | 固定为 `dynamic_vehicle_outline`。 | `dynamic_vehicle_outline` |
| `source` | 固定为 `parallel_light_projected_pbr_gaussian_outline`，即 PBR Gaussian 通过平行太阳光投射后的外轮廓。 | 同左 |
| `opacity` | 外围轮廓层基础覆盖强度。 | `0.28` |
| `opacity_distance_decay` | 沿车辆外侧距离增加时，opacity 的衰减量，范围 `0` 到 `1`。 | `0.55` |
| `opacity_distance_exponent` | opacity 距离衰减曲线指数。 | `1.25` |
| `brightness` | 外围轮廓近处的目标灰度；越低越黑。 | `0.32` |
| `brightness_distance_to_white` | 随距离向白色靠近的比例，范围 `0` 到 `1`。 | `0.65` |
| `brightness_distance_exponent` | 向白色过渡的距离曲线指数。 | `1.35` |
| `edge_softness_m` | 外围轮廓近处的边缘模糊宽度，单位米。 | `0.10` |
| `edge_softness_distance_growth_m` | 向外延伸时额外增加的边缘模糊宽度，单位米。 | `0.24` |
| `edge_softness_distance_exponent` | 边缘软化随距离增长的曲线指数。 | `1.15` |
| `distance_scale_m` | 距离衰减与边缘增长归一化距离，单位米。 | `1.25` |

#### `projection.anchor`：投影高度

| 字段 | 含义 | 默认值 |
| --- | --- | --- |
| `mode` | 固定为 `gaussian_bottom_surface`，从 Gaussian 底部支撑面确定投影平面。 | `gaussian_bottom_surface` |
| `bottom_surface_percentile` | 用于估计底面的低百分位。 | `1.0` |
| `surface_sigma` | 估计底面时沿 Z 轴扣除的协方差标准差倍数。 | `1.0` |
| `z_offset_m` | 在估计底面上的额外高度偏移，单位米；通常保持为 `0`。 | `0.0` |

## 5. 使用已有预设资产

预设资产已经是完整交付资产，通常不需要再次转换。可直接校验或作为下游渲染、手动调参、自动拟合的输入，例如：

```bash
pbr-vehicle inspect-complete \
  "$PBR_ASSET_ROOT/10010"
```

其中 canonical 配置是：

```text
$PBR_ASSET_ROOT/10010/configs/config_10010.json
```

同一 `configs/` 目录中也可能包含以 `config_` 开头的场景或自动拟合配置。下游程序应使用 canonical 的 `config_<asset-id>.json` 发现资产文件；场景配置保留场景名、时间戳和该场景的参数覆盖。
