# PBR Vehicle 太阳角识别使用指南

## 功能边界

本包输出太阳方位角 `azimuth_deg` 与高度角 `elevation_deg`。默认无 Gaussian 链路为 `SSE-v6`：

1. 在场景全部帧和相机中检测车辆；按物理实例去重，以 SAM2 mask 最大画面占比选前三辆，不要求来自同一帧。
2. MTMT 输出阴影概率；后处理执行阴影减车辆、8 连通域清理、最多两片且第二片面积至少为第一片的 50%。拟合阶段默认不再次从观测阴影扣车辆 floor（与已接受 SSE-v5-f 证据一致）。
3. 概率边缘模糊度和局部道路/车辆面积门不通过时 fail-closed。
4. 使用纯 RGB InfiniDepth 生成同帧深度和 Gaussian；车辆 mask 选择可见车辆 Gaussian，阴影像素按深度放入 3D。
5. 观测阴影和候选车辆投影逐连通域求最大相机锥形边界射线，取近相机交点之间的完整弧段。
6. 接触源图像 8 px 边界带的阴影轮廓段不计入证据。候选投影不与车辆 footprint 做布尔差集。
7. 粗 5°、局部 1°两阶段搜索，以双向稳健轮廓距离排序；IoU 只作诊断。三车中选择轮廓分数最高者。

## 安装

```bash
cd pbr-vehicle/pbr-vehicle-sun
python -m pip install -e '.[scene]'
```

完整场景链依赖外部模型代码与权重，不写死机器路径：

- Ultralytics YOLO 权重；
- SAM2 仓库与 SAM2.1 Hiera Tiny checkpoint；
- MTMT 仓库与 checkpoint；
- InfiniDepth 仓库及其 depth、GS、MoGe-2、sky checkpoints。

## 核心拟合

单帧无原生 Gaussian：

```bash
pbr-vehicle-sun-fit \
  --geometry-source feedforward_infinidepth \
  --vehicle-geometry vehicle_geometry.npz \
  --shadow-geometry shadow_geometry.npz \
  --shadow-mask shadow_postprocessed.png \
  --output-dir runs/one-frame
```

多帧时在三个输入参数后依次给出多条同帧对齐路径，程序自动切换为共享太阳角模式。场景自带可用 Gaussian 时改为 `--geometry-source native_gaussian`。

默认参数已经启用：`camera_cone_middle`、源图边缘段剔除、完整候选投影、观测阴影不扣 floor。`--feedforward-include-image-edge-shadow`、`--feedforward-subtract-predicted-floor` 和 `--feedforward-subtract-observed-floor` 仅用于复现旧合同。

## Argoverse 完整场景

```bash
pbr-vehicle-sun-scene \
  --scene 016 \
  --data-root /data/argoverse/processed/training/016 \
  --output-dir runs/argoverse016 \
  --yolo-weights /models/yolo11x.pt \
  --sam2-root /repos/sam2 \
  --sam2-checkpoint /models/sam2.1_hiera_tiny.pt \
  --mtmt-repo /repos/MTMT \
  --mtmt-checkpoint /models/MTMT.pth \
  --infinidepth-root /repos/InfiniDepth \
  --device 0
```

可用 `--sam2-python`、`--infinidepth-python` 指定各模型已有环境的 Python。数据适配要求 Argoverse 目录提供 `images/`、`road_masks/`、`intrinsics/`、`extrinsics/`、`ego_pose/` 和实例标注。

## 输出

- `scene_result.json`：逐车结果、winner、拒绝原因与全链路计时；
- 每车 `fit/fit_result.json`：太阳角、稳健轮廓指标和交点审计；
- 每车 `fit/top25_camera_visible_arc_candidates.jpg`：与最终排序相同目标的 Top-25；
- `pbr-vehicle-sun-evidence` 可将 RGB、MTMT 热力图、RGB 轮廓回投影、车辆 Gaussian、阴影深度和俯视拟合拼为高清证据图。

角度仅在阴影证据门通过时有效；跨车辆结果明显不稳定时，不应自动当作场景真值。
