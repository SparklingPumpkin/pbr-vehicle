# PBR Vehicle 太阳角识别使用指南

## 当前合同

当前版本为 `pbr-vehicle-sun 1.3.0 / SSE-v8`。`SSE-v8` 是 `SSE-v6-b` 阴影协议与 `SSE-v7` 通用多车聚合能力的组合：

1. YOLO 遍历场景全部帧/相机检测车辆。
2. SAM2.1 生成精细车辆 mask；按物理车辆去重，每辆车保留 mask 占画面比例最大的观测，选择全场景 Top 1–5，默认 Top 3。
3. SSISv2 输出 object-shadow association；以 SSIS object 与目标车辆 mask 的 IoU 绑定车辆，采用同 association ID 的 shadow。
4. `04_associated_shadow_mask.png` 原样输入后续链。禁止阴影减车辆、连通域清理、形态学修改和检测器概率图门控。
5. 同帧纯 RGB InfiniDepth 生成深度和 Gaussian；阴影按深度提升到三维，车辆 mask 从前馈 Gaussian 选择可见车辆几何，不使用 LiDAR。
6. 使用完整投影搜索画布、最大相机锥形可见轮廓、P95 双向稳健轮廓距离和两阶段网格搜索。线结构默认关闭，IoU 只作诊断。
7. 每车执行 `confidence >= 0.50` 且 `support_0.35m >= 0.75` 硬门。1 车通过即发布；2–3 车通过时增加置信度加权角和共享角联合拟合。
8. 首轮使用全局排名 1–3。只有首轮正常完成且 0 车通过时，才复用检测和排名并更换为排名 4–6；第二轮仍无车通过才 fail-closed。进程失败不触发第二轮。

## 安装

```bash
python -m pip install pbr_vehicle_sun-1.3.0-py3-none-any.whl
```

完整场景运行还要求调用方准备 YOLO、SAM2、SSISv2、InfiniDepth 的代码环境和权重。它们都通过参数传入，不写死在包内。

## 完整场景

```bash
pbr-vehicle-sun-scene \
  --scene SCENE_ID \
  --data-root DATASET_SCENE_ROOT \
  --output-dir OUTPUT_DIR \
  --yolo-weights YOLO_WEIGHTS \
  --sam2-root SAM2_REPOSITORY \
  --sam2-checkpoint SAM2_CHECKPOINT \
  --sam2-python SAM2_PYTHON \
  --ssis-root SSIS_REPOSITORY \
  --ssis-weights SSISV2_WEIGHTS \
  --ssis-python SSIS_PYTHON \
  --infinidepth-root INFINIDEPTH_REPOSITORY \
  --infinidepth-python INFINIDEPTH_PYTHON \
  --process-retries 1 \
  --device auto
```

`--device auto` 会将同一张逻辑设备分别转换为 Torch/Detectron2 使用的 `cuda:0` 和 Ultralytics 使用的 `0`。多卡环境用 `CUDA_VISIBLE_DEVICES` 选择物理卡；无 CUDA时各子步骤接收 `cpu`。

默认入口固定执行“两轮各三车”的发布合同，不接受调用方覆盖 `--top-vehicles`、`--vehicle-rank-offset`、`--selection-pool-size`、`--existing-detection` 或 `--existing-ranking`。默认使用仓库内标准 checkpoint 相对位置；也可用 `--infinidepth-depth-checkpoint`、`--infinidepth-gs-checkpoint`、`--moge2-pretrained` 和 `--sky-checkpoint` 分别覆盖。

如需研究或诊断单轮行为，使用 `pbr-vehicle-sun-scene-round`。该高级入口支持 `--top-vehicles 1..5`、`--vehicle-rank-offset` 和已有检测/排名输入，但不会自动换车。

## 已对齐输入拟合

单车或单帧：

```bash
pbr-vehicle-sun-fit \
  --geometry-source feedforward_infinidepth \
  --vehicle-geometry VEHICLE_GEOMETRY.npz \
  --shadow-geometry SHADOW_GEOMETRY.npz \
  --shadow-mask SSISV2_ASSOCIATED_SHADOW.png \
  --output-dir OUTPUT_DIR
```

1–5 辆车聚合时增加 `--aggregation-mode vehicles`，并在三个输入参数后按相同顺序分别给出各车路径。输入车辆必须属于同一物理场景且处于同一世界坐标系。

## 输出

- `two_round_result.json`：最终发布状态、发布轮次、太阳角、接受车辆全局排名和两轮执行记录。
- `round-1/scene_result.json`：排名 1–3 的选择、SSISv2 绑定、准备结果和拟合结果。
- `round-2/scene_result.json`：仅在首轮无角时生成，记录排名 4–6 的换车结果。
- `round-N/attempt-M.log`：轮级执行日志；非零退出会按 `--process-retries` 重试。
- `round-N/confidence_gated_joint_fit/multi_vehicle_fit_result.json`：逐车角度、置信度门、加权角和联合拟合。
- `round-N/confidence_gated_joint_fit/vehicle_XX/fit/fit_result.json`：独立 P95 轮廓拟合结果。
- `round-N/confidence_gated_joint_fit/vehicle_XX/fit/top25_camera_visible_arc_candidates.jpg`：与最终选择完全相同目标的候选可视化。
- `round-N/tTTT_camC/vehicle_RR_instance-ID/ssisv2_association/05_target_association_review.jpg`：目标车辆与官方 SSISv2 object-shadow pair 的绑定证据。

包内不存在旧阴影检测器或阴影 mask 后处理入口。
