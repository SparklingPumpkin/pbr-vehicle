# PBR 车辆自动识别使用指南

## 适用范围

本工具把 PBR 车辆资产的后方单视角重光照结果烘焙为普通 Gaussian 的 DC，并以车辆与普通场景 Gaussian 的 opacity 加权亮度 CDF-L1 距离选择受限光照参数。它不需要 2D RGB 图像、截图或车辆掩码。

场景输入是包含 `f_dc_0`、`f_dc_1`、`f_dc_2` 和 `opacity` 的普通 Gaussian PLY。车辆输入是 PBR 资产目录，需包含原始 Gaussian、PBR proxy、映射文件及其配置。

将车辆资产放在 `pbr-vehicle` 部署根目录下的 `Assets/pbr_assets/<车辆名>`。下文路径均相对此部署根目录或 `pbr-vehicle-auto` 工作目录。

## 安装

```bash
cd pbr-vehicle/pbr-vehicle-auto
python -m pip install -e .
```

如需运行测试：

```bash
python -m pip install -e '.[test]'
python -m pytest -q
```

## 自动识别示例

以下示例以 `10010` 资产和一个普通 Gaussian 场景为例。输出配置写回该资产的 `configs` 目录，过程文件写入独立的 `runs` 目录。

```bash
pbr-vehicle-auto-fit \
  --scene-ply Scenes/argoverse004/background.ply \
  --asset-dir ../Assets/pbr_assets/10010 \
  --template-config src/pbr_vehicle_auto/templates/default_vehicle_pbr_viser_template.json \
  --output-dir runs/argoverse004-10010-auto \
  --final-config ../Assets/pbr_assets/10010/configs/config_auto_10010_argoverse004.json \
  --max-seconds 120 \
  --bins 512
```

参数含义：

- `--scene-ply`：待适配场景的普通 Gaussian PLY。它是亮度分布的目标，不要求场景具备 PBR 属性。
- `--asset-dir`：一个车辆资产目录，默认部署位置是 `Assets/pbr_assets/<车辆名>`。目录内文件名由模板的 `pbr_asset.files` 指定。
- `--template-config`：完整 Viser 状态模板。车辆位置、旋转、投影、材质、太阳方向和太阳 RGB 等非拟合字段从该文件继承。省略时使用包内同一默认模板。
- `--output-dir`：本次运行的诊断目录。会写入候选列表、指标 JSON 和烘焙后的普通 Gaussian DC PLY。
- `--final-config`：最终自动识别配置的输出文件。候选没有改善目标时，文件仍会生成，但保留模板外观并标记 `rejected_no_improvement`。
- `--max-seconds`：整个候选搜索的时间上限，单位为秒。默认值为 `480`。
- `--bins`：亮度 CDF 的直方图 bin 数。默认值为 `512`；增加该值会提高分布比较精度并略增计算量。

## 拟合与保留的参数

自动搜索仅包含：

- `sun_intensity`：控制直射太阳造成的受光面亮度。
- `ambient_fill`：控制车辆补光，用于避免背光面过暗。
- `environment_cct_kelvin`：在 `3500-7200 K` 的固定能量色温轨道中选择环境光颜色。

下列参数不参与自动搜索，始终从模板保留：太阳方向、太阳 RGB、车辆材质、车辆姿态、投影、场景状态及其他 Viewer 状态。`material.saturation` 仅供手动调节，自动识别不会修改它。

模板中的 `projection.extension.brightness_distance_to_white` 固定为 `0.0`，避免投影延伸部分随距离向白色偏移。

## 输出解释

`metrics.json` 中的 `metric.raw` 是原始车辆 DC 与场景 DC 的距离，`metric.baked` 是本次烘焙后的距离，`improvement_percent` 为相对改善百分比。`candidates.json` 记录每一个候选的搜索参数与分数。烘焙 PLY 仅含 DC，所有高阶 SH 系数均被清零。
