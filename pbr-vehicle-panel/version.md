# pbr-vehicle-panel 版本说明

## 当前版本：1.7.1

- 换 PTH 场景时读取相邻 `config.yaml`，动态绑定对应 `data_root + scene_idx`，避免太阳估计沿用旧场景数据。
- 两轮太阳估计显示车辆检测、分割、几何准备、逐车拟合和发布门进度；只读取 `published_round` 指定轮次。
- 发布太阳角后同时更新共享场景与所有现有车辆的主/高级角度控件，不改变车辆共享/独立光照模式。
- PTH 加载支持 NumPy 2 pickle 名称在 NumPy 1.x 环境中反序列化，并用锁和原子替换保护并发缓存。
- 移除场景数据根解析中的机器绝对路径假设，支持从 checkpoint 目录祖先推导相对数据目录。
- 放宽 Panel 的 SciPy 兼容范围到 `>=1.9,<2`，解除与 `pbr-vehicle-sun 1.2.0` 的安装依赖冲突。

## 1.7.0

- 新增逐车 Environment-map 环境球预览，将六面 cubemap 重采样为经纬图并贴到可视化球体。
- 环境球支持独立 XYZ 采样位置；位置变化会隐藏所有插入车辆、投影及其他环境球后重新捕获。
- 新增“跟随车辆”：采样中心锁定车辆中心，显示球使用独立 XYZ 相对偏移，防止与车辆重叠遮挡。
- 环境球预览与车辆 IBL 开关相互独立；仅预览时仍保持车辆原有 SH 着色，关闭预览会移除球体。
- 配置文件保存环境球可见性、跟随模式、独立采样位置和显示偏移。

## 1.6.0

- 新增默认关闭的逐车“使用场景环境贴图”分支；关闭时保持原有环境 SH/固定视线预览路径不变。
- 在车辆中心捕获六个 scene-only `90°` 视图；捕获时临时隐藏全部插入车辆及投影，避免目标车辆反射自身。
- Cubemap 漫反射投影为二阶 irradiance SH；镜面反射使用 `reflect(-V,N)`，并按车辆 roughness 选择多级 cubemap mip。
- 车辆移动、旋转或缩放时使 cubemap 缓存失效并重建；观察相机移动时复用 cubemap，只重新计算车辆 Gaussian RGB。
- 面板提供每面 `32/64/128/256` 分辨率和手动刷新；配置文件保存开关及分辨率。
- 新增 `--enable-environment-map` 与 `--environment-map-resolution` 启动参数，捕获失败时自动回退旧路径。

## 1.5.0

- 每辆车顶部新增“Auto 识别车辆参数”按钮，对接 `pbr-vehicle-auto 1.2.0 / ALM-v5`。
- Auto 在后台运行，以点击时的完整车辆状态为模板，只回填太阳光强度、亮度和车辆色温；角度、太阳 RGB、饱和度和其他材质保持不变。
- 只有 `candidate_only` 会应用结果；`rejected_no_improvement`、失败和超时均保持当前面板不变。
- PLY 直接使用完整场景；PTH 自动转换为完整缓存 PLY，不受 Viewer 显示点数影响。
- 拟合输出、诊断和烘焙 PLY 保留在系统临时目录；调用命令由可移植 JSON 配置，不写机器绝对路径。

## 1.4.0

- Scene 面板新增“太阳估计”按钮，对接 `pbr-vehicle-sun 1.1.0 / SSE-v8` 的公开场景入口。
- 估计在后台线程运行，不阻塞 Viser 交互；所有中间产物写入并保留在系统临时目录。
- 优先采用多车联合拟合角度，回退到置信度加权角或单车角度；未发布有效角度时保持现有参数不变。
- 将 SSE 的路面坐标太阳方向转换为 Panel 坐标，成功后自动启用太阳并回填共享方位角和高度角。
- 外部模型、权重和 Python 环境由可移植 JSON 提供，交付包不写入机器绝对路径。

## 1.3.1

- 顶层车辆面板使用中文参数：太阳光强度、太阳方位角、太阳高度角、车辆色温、饱和度、亮度和 Center orbit。
- 色温滑条范围为 `-0.5~0.5`，映射 `2000~12000K`，`0=6500K`。
- 饱和度为直接倍率 `0~2`，`1` 为中性；亮度为 `-1~1`，`0` 对应内部 fill light `0.35`。
- 太阳光强度继续使用 `-1~1`，角度继续使用度数；配置文件保存内部兼容物理量。
- 主线 DriveStudio Viewer 与独立 Viser 交付包保持同一参数映射。
- 修复低太阳高度下 cast extension 只绘制投影终点、与车辆脱离的问题；extension 现在覆盖车辆 footprint 到投影终点 footprint 的完整平行光扫掠区域，方向保持为太阳方位角加 `180` 度。

## 1.3.0

- 暴露参数改为中文，增加亮度命名和统一归一化控制。
- 独立交付包支持单 PLY `pbr-vehicle-single-ply-v1` 资产合同。
- 增加渲染原理、公式、Viser buffer 和普通 Gaussian 差异说明。

## 1.2.x

- 增加中文使用指南、可移植相对路径示例和 PTH 场景转换说明。
- 清理交付包中的机器绝对路径，真实资产测试改为环境变量可选启用。
- 完成六项快捷参数、单层高级分类、Config 隔离、双向镜像和多车辆控制。

## 1.1.x

- 从 DriveStudio 链路拆出独立 Viser 面板。
- 支持场景 PLY/PTH、车辆添加/删除、逐车或共享光照、配置保存/加载。
- 使用固定车底 contact core 与动态 cast extension 两层程序化投影。

## 1.0.x

- 建立 Gaussian PBR 车辆面板的首个独立交付版本。
- 支持车辆变换、材质、R3GW 光照、投影调节和全量 Gaussian 加载。

## 维护规则

每次发布新版本时同步更新 `pyproject.toml`、`MAINLINE_MANIFEST.json`、`DELIVERY_REPORT.md`、本文件、测试和 `dist/SHA256SUMS`。资产合同变化记录在 `../Assets/version.md`，转换器和自动拟合工具分别记录在各自子项目的 `version.md`。
